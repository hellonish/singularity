Core skills

1. Query decomposition

Break a broad request into focused subquestions.

“Research NVIDIA’s AI growth”
→ revenue growth
→ product demand
→ competition
→ supply constraints
→ regulatory risks

2. Tool routing

Choose the right tools for the domain.

Medical → PubMed + ClinicalTrials
Financial → SEC EDGAR + Company Facts
Technical → GitHub + official documentation
General → Web search + web fetch

3. Search planning

Generate search queries, date filters, source priorities, and stopping criteria.

4. Source discovery

Find relevant sources across the web, papers, filings, repositories, and official databases.

5. Source extraction

Convert webpages, PDFs, APIs, tables, and repositories into normalized evidence.

6. Evidence ranking

Score sources using:

Authority
Relevance
Recency
Directness
Independence
Completeness

7. Deduplication

Remove repeated articles, mirrored pages, duplicate API records, and syndicated reporting.

8. Claim–evidence mapping

Every important claim should point to supporting evidence.

{
  "claim": "Revenue increased 18%",
  "source_ids": ["sec_123"],
  "supporting_passage": "...",
  "confidence": 0.96
}

9. Contradiction detection

Identify when reliable sources disagree and preserve both positions instead of hiding the conflict.

10. Citation verification

Confirm that:

The URL exists
The cited passage supports the claim
Dates and numbers match
The source is not being misrepresented

11. Research sufficiency

Decide whether enough evidence has been collected or another search cycle is required.

This prevents both premature answers and endless searching.

12. Context compression

Summarize accumulated research without losing:

Key claims
Sources
Numbers
Uncertainties
Open questions
